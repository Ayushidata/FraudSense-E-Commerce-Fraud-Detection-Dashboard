# FraudSense-E-Commerce-Fraud-Detection-Dashboard
FraudSense is a modern AI-powered fraud analytics dashboard for e-commerce transaction monitoring and anomaly detection.
Built using Python, Dash, Plotly, and Isolation Forest, the system provides:

Real-time fraud risk visualization
Interactive ML dashboards
Transaction anomaly scoring
Statistical analysis & EDA
Model benchmarking
System architecture visualization

The dashboard simulates a production-grade fraud monitoring platform with a sleek cybersecurity-inspired UI.
